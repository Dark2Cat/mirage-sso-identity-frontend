# Mirage SSO Identity Front

React 18.2 + Vite 5 前端项目，用于 Mirage SSO 单点登录认证中心。

## 技术栈

- React 18.2
- Vite 5
- TypeScript 5.4
- React Router 6
- Zustand
- Axios
- Lucide React

## 本地启动

```bash
npm install
npm run dev
```

默认访问：

```text
http://localhost:5173
```

后端 API 默认代理到：

```text
http://localhost:18082
```

默认联调账号：

```text
admin / mirage@2026
```
